# Calculadora em Java 🧮

Aplicação de calculadora de consola desenvolvida em Java para praticar lógica de programação, estruturas de controlo e tratamento de exceções.

## 🚀 Funcionalidades
* Operações matemáticas básicas: Adição (+), Subtração (-), Multiplicação (*) e Divisão (/).
* Menu interativo que permite realizar múltiplos cálculos numa única execução.
* Tratamento de erros para entradas inválidas (ex: digitação de letras em vez de números).

## 🛠️ Tecnologias Utilizadas
* **Java** (JDK 17 ou superior)
* **IDE:** Visual Studio Code

## 💻 Como Executar o Projeto

1. Certifique-se de que tem o Java (JDK) instalado no seu computador.
2. Clone este repositório ou descarregue o ficheiro `CalculadoraApp.java`.
3. Abra o terminal na pasta onde está o ficheiro e compile o código:
   ```bash
   javac CalculadoraApp.java
